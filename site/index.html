محضر الدروس

التطبيق الذكي للمعلمين: حوّل كتبك ومقرراتك إلى وحدات ودروس منضّمة، مع ١٢ أداة ذكاء اصطناعي للتحضير والتلخيص والخرائط الذهنية والاختبارات والأنشطة ومتابعة الطلاب — وكل بياناتك محفوظة محلياً على جهازك.

📱 Android 💻 Windows / Linux / macOS 📦 نسخ احتياطي عبر Google Drive 🔒 خصوصية — بياناتك على جهازك

التحميل حسب توزيعة لينكس

Ubuntu / Debianملف .deb من صفحة الإصدارات أسفل.
جميع التوزيعات الحديثةملف .AppImage — نفّذه بعد chmod +x.
Flatpak / Flathubالتقديم قيد المراجعة — بمجرد قبوله: flatpak install flathub org.mahdara.durus.
Arch / AURحزمة PKGBUILD قيد الإضافة إلى AUR.

جميع روابط التنزيل المباشرة موجودة في صفحة الإصدارات أسفلها (فاتح تُحمَّل تلقائياً من GitHub Releases).

التحميل على أجهزة أخرى

Android متاح

  • Google Play (قريباً) أو APK / AAB من صفحة الإصدارات.

Windows متاح

  • مثبّت .exe أو .msi — لا يحتاج تثبيت إضافي.

macOS متاح

  • ملف .dmg لإصدار Apple Silicon وIntel.

iPhone / iPad قريباً

  • التطبيق جاهز؛ الإتاحة على App Store بعد التوقيع والتقديم.
